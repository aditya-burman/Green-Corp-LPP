Decision Science (DS) • EMBA Term 2

1. Problem Statement

GreenCorp Sustainable Manufacturing Firm produces two primary eco-friendly lines: Eco-Packaging Boxes (x₁) and Biodegradable Bottles (x₂). Management must determine the monthly production mix to maximize total profit (Z) while remaining within capacity limits for machine hours, skilled assembly labor, and strict environmental regulatory carbon emission quotas.

2. Linear Programming Problem (LPP) Formulation

Maximize Z = 40x₁ + 60x₂

Subject to Operational Constraints:

  • Machine Hours: 2x₁ + 3x₂ ≤ 120 hrs
  • Skilled Labor: 1x₁ + 2x₂ ≤ 80 hrs
  • Carbon Cap: 4x₁ + 2x₂ ≤ 160 units
  • Non-negativity: x₁, x₂ ≥ 0

3. Implementation & Results

The interactive HTML5 application maps constraints into a real-time Cartesian Feasible Region. Evaluating the candidate corner points using the Simplex algorithm yields:

  • (0, 0) → Profit = $0
  • (0, 40) → Profit = $2,400 (Violates Carbon Cap)
  • (40, 0) → Profit = $1,600
  • (30, 20) [OPTIMAL] → Profit = $2,400 (Feasible)
