■ Optimization model

Binary decision variable x■ ∈ {0,1}: 1 if treasure i is selected. Maximize Σ gold■ × x■ subject to the stage constraints. The game checks every possible combination (at most 2■ = 256) to verify the global optimum.

This is a binary integer linear programming game (0–1 knapsack and its extensions), not a continuous-variable simplex exercise. All data are fictional educational assumptions.
